The application object returned by `Library.new()` is the entry point for the entire library.

## `Library.new(config)`

Creates the root `ScreenGui`, loads configuration, initializes Quick Commands, and creates the built-in `Settings` tab.

```lua
local app = Library.new({
	Name = "Universal Utility",
	SaveFolder = "Configs",
	SaveId = "settings",
	AccentColor = Color3.fromRGB(70, 0, 180),
	TextColor = Color3.fromRGB(255, 255, 255),
})
```

<ParamField path="config" type="table" optional>
Application configuration. Omit the table to use the built-in defaults.
</ParamField>

<ParamField path="config.Name" type="string" default='"Unnamed"'>
Library name used in internal state and console messages.
</ParamField>

<ParamField path="config.SaveFolder" type="string" default='""'>
Folder used for the JSON configuration file. When empty, the config is stored as `<SaveId>.json`.
</ParamField>

<ParamField path="config.SaveId" type="string" default='"config"'>
Base name for the JSON configuration file. The `.json` extension is added automatically.
</ParamField>

<ParamField path="config.AccentColor" type="Color3" optional>
Initial accent color. `Accent` is accepted as an alias.
</ParamField>

<ParamField path="config.TextColor" type="Color3" optional>
Initial text color. `Text` is accepted as an alias.
</ParamField>

<Note>
`Library.new()` also creates a tab named `Settings`. Calling `CreateTab("Settings")` later returns that existing tab.
</Note>

## Methods

### `app:CreateTab(name, defaultPosition)`

Creates a draggable floating tab. Reusing an existing tab name returns the existing tab object.

```lua
local combat = app:CreateTab("Combat")
local movement = app:CreateTab(
	"Movement",
	UDim2.new(0, 260, 0, 80)
)
```

<ParamField path="name" type="string" required>
Tab title and the key used for saved tab position/state.
</ParamField>

<ParamField path="defaultPosition" type="UDim2" optional>
Initial pixel position used only when the tab has no saved position.
</ParamField>

<Note>
New tabs start minimized. Without a saved position or explicit position, the library stacks them vertically. Dragging is viewport-clamped and can use grid snapping.
</Note>

### `app:GetTab(name)`

Returns an existing tab object or `nil` if the name is not registered.

```lua
local settings = app:GetTab("Settings")
if settings then
	settings:AddLabel("Additional settings")
end
```

### `app:ToggleGui(forcedState)`

Shows or hides every floating tab. The Quick Commands overlay remains available.

```lua
app:ToggleGui()      -- Toggle
app:ToggleGui(true)  -- Show
app:ToggleGui(false) -- Hide
```

<ParamField path="forcedState" type="boolean" optional>
When supplied, visibility is set directly instead of toggled.
</ParamField>

The same action is bound to **Right Shift** by default. The key can be changed from the built-in `Settings` tab.

### `app:SetAccentColor(color)`

Changes the accent color at runtime and notifies components that listen for theme changes.

```lua
app:SetAccentColor(Color3.fromRGB(0, 200, 255))
```

<ParamField path="color" type="Color3" required>
New accent color. Non-`Color3` values are ignored.
</ParamField>

### `app:SetTextColor(color)`

Changes the primary UI text color at runtime.

```lua
app:SetTextColor(Color3.fromRGB(245, 245, 245))
```

<ParamField path="color" type="Color3" required>
New text color. Non-`Color3` values are ignored.
</ParamField>

### `app:SetTheme(themeTable)`

Sets accent and text colors together.

```lua
app:SetTheme({
	Accent = Color3.fromRGB(255, 80, 160),
	Text = Color3.fromRGB(255, 255, 255),
})
```

Accepted keys:

| Theme key | Alias | Effect |
| :--- | :--- | :--- |
| `Accent` | `AccentColor` | Updates the global accent color. |
| `Text` | `TextColor` | Updates the global text color. |

### `app:ExportQuickCommandsList()`

Prints every registered Quick Command, returns the same entries as a Lua array, and writes a text file when the environment exposes `writefile`.

```lua
local commands = app:ExportQuickCommandsList()
for _, line in ipairs(commands) do
	print(line)
end
```

The file path is:

```text
<SaveFolder>/commandIds/<SaveId>.txt
```

When `SaveFolder` is empty, that becomes:

```text
commandIds/<SaveId>.txt
```

Each line contains the command title, command ID, aliases, and usage when applicable.

## Complete application surface

The bundled public application API is:

```text
Library.new(config)
app:CreateTab(name, defaultPosition)
app:GetTab(name)
app:ToggleGui(forcedState)
app:SetAccentColor(color)
app:SetTextColor(color)
app:SetTheme(themeTable)
app:ExportQuickCommandsList()
```

`ConfigManager`, `KeybindManager`, `State`, and component `.create()` functions are bundled implementation modules, not part of the stable application contract.
