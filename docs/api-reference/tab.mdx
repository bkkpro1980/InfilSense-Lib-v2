title: "Tab API"

A `Tab` is a draggable, collapsible floating window. Each tab owns its component list, flyout area, saved position, and minimized state.

## Component builders

| Method | Returns | Purpose |
| :--- | :--- | :--- |
| `tab:AddButton(config)` | Button handle | One-shot action or boolean toggle. |
| `tab:AddSlider(config)` | Slider handle | Numeric or boolean slider. |
| `tab:AddInput(config)` | Input handle | Text submission or toggle input. |
| `tab:AddTextBox(config)` | Input handle | Alias of `AddInput`. |
| `tab:AddTextbox(config)` | Input handle | Alias of `AddInput`. |
| `tab:AddSelection(config)` | Selection handle | Single-select picker or nested flyout container. |
| `tab:AddLabel(config)` | Label handle | Static text row. |

```lua
local tab = app:CreateTab("Main")

tab:AddLabel("Player")
tab:AddButton({ Info = { Title = "Heal" } })
tab:AddSlider({ Info = { Title = "WalkSpeed" }, Min = 16, Max = 100, Default = 16 })
tab:AddInput({ Info = { Title = "Message" } })
tab:AddSelection({ Info = { Title = "Target" } })
```

<Note>
The implementation accepts an internal second parameter (`pOverride`) on component builders when the library renders nested flyouts. Normal application code should omit it.
</Note>

## `tab:GetFrame()`

Returns the tab header `TextLabel` instance.

```lua
local header = tab:GetFrame()
header.TextSize = 20
```

## `tab:closeMore()`

Closes the tab's currently open flyout.

```lua
tab:closeMore()
```

## Complete tab surface

The user-facing tab API is:

```text
tab:AddButton(config)
tab:AddInput(config)
tab:AddTextBox(config)  -- alias
tab:AddTextbox(config)  -- alias
tab:AddSelection(config)
tab:AddSlider(config)
tab:AddLabel(config)
tab:GetFrame()
tab:closeMore()
```

The methods `openMore()` and `buildContextMenu()` are implementation helpers used by built-in flyouts and are intentionally not treated as stable application API.
