---
title: "Buttons & Toggles"
description: "Create one-shot actions and stateful boolean controls."
---

Buttons register with Quick Commands automatically. By default they execute once; `InternalInfo.Toggle = true` turns the same component into a boolean toggle.

## Action button

```lua
tab:AddButton({
	Info = {
		Title = "Respawn",
		Description = "Reset the local humanoid health.",
	},
	InternalInfo = {
		UniqueCommandId = "respawn",
		Aliases = { "re", "reset" },
	},
	Callback = function()
		local player = game.Players.LocalPlayer
		local character = player.Character
		local humanoid = character and character:FindFirstChildOfClass("Humanoid")
		if humanoid then
			humanoid.Health = 0
		end
	end,
})
```

A normal button callback receives no arguments.

## Toggle button

```lua
tab:AddButton({
	Info = {
		Title = "Noclip",
		Description = "Toggle the local noclip feature.",
	},
	InternalInfo = {
		Toggle = true,
		UniqueCommandId = "noclip",
		Bindable = true,
		StartupAvailable = true,
		Aliases = { "nc" },
	},
	Callback = function(enabled)
		print("Noclip:", enabled)
	end,
})
```

Toggle callbacks receive the new boolean state.

## Configuration

<ParamField path="Info.Title" type="string" default='"Button"'>
Button title. For toggles this is also the displayed toggle label.
</ParamField>

<ParamField path="Info.Description" type="string" optional>
Tooltip text displayed after the pointer rests over the control for about one second.
</ParamField>

<ParamField path="InternalInfo.UniqueCommandId" type="string" optional>
Stable command ID. A random ID is generated when omitted.
</ParamField>

<ParamField path="InternalInfo.Toggle" type="boolean" default="false">
Turns the action button into a stateful boolean toggle.
</ParamField>

<ParamField path="InternalInfo.Bindable" type="boolean" default="false">
Adds a right-click menu for assigning or removing a keyboard shortcut.
</ParamField>

<ParamField path="InternalInfo.StartupAvailable" type="boolean" default="false">
Adds a right-click **Toggle Startup** option. For buttons, a saved startup flag executes the callback with `true` during the next library initialization.
</ParamField>

<ParamField path="Aliases" type="string[]" optional>
Alternate Quick Commands names. `Info.Aliases` and `InternalInfo.Aliases` are also recognized.
</ParamField>

<ParamField path="Callback" type="function" optional>
Normal button: `Callback()`. Toggle button: `Callback(state)`.
</ParamField>

## Quick Commands

Normal buttons are invoked by command name or alias:

```text
respawn
re
```

Toggle buttons accept an explicit state or flip when no state is supplied:

```text
noclip on
noclip off
noclip true
noclip false
noclip
```

## Right-click actions

When `Bindable` or `StartupAvailable` is enabled, right-clicking the button opens its flyout.

- **Assign a New Keybind** stores the selected keyboard key by command ID.
- **Remove Keybind** clears the saved binding.
- **Toggle Startup** stores the startup flag.

## Returned handle

`AddButton()` returns a handle with both GUI references and control methods:

```lua
local button = tab:AddButton({
	Info = { Title = "Example" },
	InternalInfo = { Toggle = true },
	Callback = function(state)
		print(state)
	end,
})

print(button:getId())
print(button:getValue())

button.setVisualState(true)
button.activate()
```

| Member | Behavior |
| :--- | :--- |
| `frame` | Outer `Frame` instance. |
| `button` | Clickable `ImageButton`. |
| `text` | Title `TextLabel`. |
| `isToggle` | Boolean indicating toggle mode. |
| `getValue()` | Current stored state. Normal buttons usually remain `false`; toggles return a boolean. |
| `getId()` | Resolved command ID. |
| `updateText()` | Refreshes the title and any saved keybind suffix. |
| `setVisualState(state)` | Updates stored toggle state and visuals. |
| `activate()` | Executes the button using the same callback path as a click. |

<Warning>
`activate()` and `setVisualState()` are convenient programmatic hooks, but they do not add new persistence semantics beyond what the component already implements.
</Warning>
