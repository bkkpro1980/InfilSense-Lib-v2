---
title: "Inputs"
description: "Collect text with standard submit inputs or toggle inputs."
---

`AddInput()` creates a text box paired with an action button. `AddTextBox()` and `AddTextbox()` are exact aliases of the same builder.

## Standard input

```lua
local input = tab:AddInput({
	Info = {
		Title = "Message",
		Description = "Text sent to the callback.",
	},
	DefaultText = "Hello",
	InternalInfo = {
		UniqueCommandId = "message",
		Aliases = { "msg" },
	},
	Callback = function(text)
		print("Message:", text)
	end,
})
```

Clicking the action button calls `Callback(text)`. Pressing **Enter** in the text box also submits the current text.

## Toggle input

Set `InternalInfo.Toggle = true` to use the adjacent button as a boolean toggle:

```lua
tab:AddInput({
	Info = {
		Title = "Prefix",
		Description = "Enable a custom chat prefix.",
	},
	DefaultText = "[VIP]",
	InternalInfo = {
		Toggle = true,
		UniqueCommandId = "prefix",
		Aliases = { "tag" },
	},
	Callback = function(enabled, text)
		print(enabled, text)
	end,
})
```

Toggle callbacks receive **two arguments**: `Callback(state, text)`.

The behavior is:

| Action | Callback |
| :--- | :--- |
| Click toggle button | `Callback(newState, currentText)` |
| Press Enter while enabled | `Callback(true, currentText)` |
| Press Enter while disabled | No callback execution |

## Configuration

<ParamField path="Info.Title" type="string" default='"Submit" (or "Toggle")'>
Text displayed on the action half of the control.
</ParamField>

<ParamField path="Info.Description" type="string" optional>
Tooltip text displayed when the pointer rests over the action area.
</ParamField>

<ParamField path="DefaultText" type="string" default='""'>
Initial textbox value.
</ParamField>

<ParamField path="InternalInfo.Toggle" type="boolean" default="false">
Enables two-argument toggle behavior.
</ParamField>

<ParamField path="InternalInfo.UniqueCommandId" type="string" optional>
Stable Quick Commands ID. A random ID is generated when omitted.
</ParamField>

<ParamField path="InternalInfo.Bindable" type="boolean" default="false">
Adds a right-click menu for assigning or removing a keyboard shortcut.
</ParamField>

<ParamField path="InternalInfo.StartupAvailable" type="boolean" default="false">
Adds a persisted startup flag to the context menu. The current input implementation does not execute the input callback automatically from that flag on startup.
</ParamField>

<ParamField path="Aliases" type="string[]" optional>
Alternate Quick Commands names. `Info.Aliases` and `InternalInfo.Aliases` are also accepted.
</ParamField>

<ParamField path="Callback" type="function" optional>
Standard input: `Callback(text)`. Toggle input: `Callback(state, text)`.
</ParamField>

## Quick Commands

Standard input concatenates all arguments into the textbox value:

```text
message hello from quick commands
```

Toggle input supports an optional state prefix:

```text
prefix on [VIP]
prefix off [VIP]
prefix [VIP]
```

The explicit forms `on`, `true`, `1`, `off`, and `false` are recognized. Without a state prefix, the supplied arguments replace the textbox text and enable the toggle.

## Returned handle

```lua
local input = tab:AddInput({
	Info = { Title = "Message" },
	Callback = function(text)
		print(text)
	end,
})

print(input:getId())
print(input:getValue())
print(input:isToggled())
```

| Method | Result |
| :--- | :--- |
| `getValue()` | Current textbox text. |
| `getId()` | Resolved command ID. |
| `isToggled()` | `true` only when the input is a toggle whose stored state is enabled. |

## Aliases

These three builders are equivalent:

```lua
tab:AddInput(config)
tab:AddTextBox(config)
tab:AddTextbox(config)
```
