Inputs combine a text box with an adjacent action or toggle button.

## Action Input

Pressing the submit button (or hitting `Enter` inside the textbox) passes the text string to the callback:

```lua
tab:AddInput({
	Info = {
		Title = "Teleport",
		Description = "Type a player username to teleport."
	},
	DefaultText = "Username",
	InternalInfo = {
		UniqueCommandId = "goto_player",
		Aliases = { "goto", "tp" }
	},
	Callback = function(text)
		print("Target:", text)
	end
})
```

## Toggle Input

Set `InternalInfo.Toggle = true`. When toggled **on**, it passes the string; when toggled **off**, it passes `nil`. Editing text while active immediately calls the callback with the updated value.

```lua
tab:AddInput({
	Info = {
		Title = "Chat Spammer",
		Description = "Periodically sends the entered text to chat."
	},
	DefaultText = "Hello World!",
	InternalInfo = {
		Toggle = true,
		UniqueCommandId = "chat_spammer",
		Aliases = { "spam" }
	},
	Callback = function(text)
		if text then
			print("Spamming:", text)
		else
			print("Stopped spamming.")
		end
	end
})
```

<Note>
	Toggle mode is set via `InternalInfo.Toggle`, not a top-level `Toggle` field. There is no separate `AddToggleInput` method — always call `tab:AddInput(config)`.
</Note>

## Parameters

<ParamField path="Info.Title" type="string" default='"Submit" (or "Toggle" if InternalInfo.Toggle is true)'>
	Text displayed on the adjacent action/toggle button.
</ParamField>

<ParamField path="Info.Description" type="string" optional>
	Tooltip text shown on hover.
</ParamField>

<ParamField path="DefaultText" type="string" default='""'>
	Initial text populating the textbox.
</ParamField>

<ParamField path="InternalInfo.UniqueCommandId" type="string" optional>
	Stable identifier used for saved keybinds, startup state, and Quick Commands lookup.
</ParamField>

<ParamField path="InternalInfo.Toggle" type="boolean" default="false">
	When `true`, the adjacent button becomes a toggle. `Callback` receives the textbox text while on, and `nil` while off.
</ParamField>

<ParamField path="InternalInfo.Bindable" type="boolean" default="false">
	When `true`, right-clicking opens a context menu to assign a keyboard shortcut that activates the input.
</ParamField>

<ParamField path="InternalInfo.StartupAvailable" type="boolean" default="false">
	When `true`, right-clicking opens a context menu option to auto-run this input on script start.
</ParamField>

<ParamField path="InternalInfo.Aliases" type="string[]" default="{}">
	Alternate names this input responds to in Quick Commands.
</ParamField>

<ParamField path="Callback" type="function" required>
	Called when the input is submitted (`Enter` or button click). Receives the entered text, or `(text | nil)` in toggle mode.
</ParamField>

## Input Object Methods

The object returned by `:AddInput()` exposes the following helpers:

```lua
local input = tab:AddInput({ ... })

local text = input:getValue()		-- Returns the current textbox contents
local id = input:getId()			-- Returns the resolved UniqueCommandId
local isOn = input:isToggled()		-- Returns the toggle state (Toggle mode only)
```
