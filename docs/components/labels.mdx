---
title: "Labels"
description: "Add static text for headings, section labels, and lightweight metadata."
---

Labels are non-interactive rows intended for headings, descriptions, and separators.

## Simple label

```lua
tab:AddLabel("Player Configuration")
```

## Styled label

```lua
tab:AddLabel({
	Text = "<b>Character Settings</b>",
	TextColor3 = Color3.fromRGB(200, 200, 200),
	TextSize = 14,
})
```

Rich text uses Roblox's native `TextLabel.RichText` markup and is enabled by default:

```lua
tab:AddLabel({
	Text = "<font color=\"#9D7BFF\"><b>Character</b></font> <i>Settings</i>",
})
```

Set `RichText = false` to opt out. The option is also supported on button, input,
selection, and slider configs. For those components it formats the title and its
description tooltip. You can set it on the component config or inside `Info`:

```lua
tab:AddButton({
	Info = {
		Title = "<b>Heal</b>",
		Description = "<font color=\"#9D7BFF\">Restores health.</font>",
	},
})
```

`Info.Title` is accepted as a fallback when `Text` is not supplied:

```lua
tab:AddLabel({
	Info = { Title = "Advanced Settings" },
})
```

## Parameters

<ParamField path="config" type="string | table" required>
Use a string for the simplest form or a table for styling.
</ParamField>

<ParamField path="Text" type="string" default='"Label"'>
Label content. `Info.Title` is used as a fallback.
</ParamField>

<ParamField path="Info.Title" type="string" optional>
Fallback label content when `Text` is absent.
</ParamField>

<ParamField path="TextColor3" type="Color3" optional>
Custom text color for this label.
</ParamField>

<ParamField path="TextSize" type="number" default="13">
Text size in pixels.
</ParamField>

<ParamField path="RichText" type="boolean" default="true">
Enables Roblox rich-text tags such as `<b>`, `<i>`, `<u>`, `<s>`, `<font>`, and `<br>`.
Set to `false` to render the content as plain text.
</ParamField>

## Returned handle

```lua
local label = tab:AddLabel("Initial text")

label:SetText("Updated text")
print(label:GetText())
```

| Member | Behavior |
| :--- | :--- |
| `frame` | Outer label `Frame`. |
| `textLabel` | Underlying `TextLabel`. |
| `SetText(text)` | Replaces the label text. |
| `SetRichText(enabled)` | Enables or disables rich-text rendering. |
| `GetText()` | Returns the current label text. |
| `GetRichText()` | Returns whether rich-text rendering is enabled. |
