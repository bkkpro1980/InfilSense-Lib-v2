---
title: "Selections"
description: "Build single-select pickers or nested component flyouts."
---

`AddSelection()` creates a row with a flyout. With `SingleSelect = true`, the flyout behaves as a picker; without it, the component is most useful as a nested menu container.

## Single-select picker

```lua
local target = tab:AddSelection({
	Info = {
		Title = "Target",
		Description = "Choose which target to use.",
	},
	SingleSelect = true,
	DefaultValue = "Nearest",
	InternalInfo = {
		UniqueCommandId = "target",
		Aliases = { "dest" },
	},
	Callback = function(value)
		print("Selected:", value)
	end,
})

target:AddOption({ Info = { Title = "Nearest" }, Value = "Nearest" })
target:AddOption({ Info = { Title = "Self" }, Value = "Self" })
target:AddOption({ Info = { Title = "Last Target" }, Value = "LastTarget" })
```

`SingleSelect` can be supplied as either:

```lua
SingleSelect = true
```

or:

```lua
InternalInfo = { SingleSelect = true }
```

## Option callbacks

An option can supply its own callback:

```lua
target:AddOption({
	Info = { Title = "Nearest" },
	Value = "Nearest",
	Callback = function(optionEnabled, selectionValue)
		print(optionEnabled, selectionValue)
	end,
})
```

For single-select selections, the library stores the selected option `Value` and clears the stored value when that option is turned off.

## Nested submenu

A non-single-select selection can act as a lightweight submenu that contains other components:

```lua
local settings = tab:AddSelection({
	Info = { Title = "ESP Configuration" },
	InternalInfo = { UniqueCommandId = "esp_config" },
})

settings:AddLabel("Visual Settings")

settings:AddButton({
	Info = { Title = "Show Tracers" },
	InternalInfo = { Toggle = true },
	Callback = function(enabled)
		print("Tracers:", enabled)
	end,
})

settings:AddSlider({
	Info = { Title = "Max Distance" },
	Min = 100,
	Max = 3000,
	Default = 1000,
	Callback = function(distance)
		print("Distance:", distance)
	end,
})

settings:AddTextBox({
	Info = { Title = "Filter" },
	DefaultText = "All",
	Callback = function(text)
		print("Filter:", text)
	end,
})
```

## Configuration

<ParamField path="Info.Title" type="string" default='"Selection"'>
Text shown on the parent row.
</ParamField>

<ParamField path="Info.Description" type="string" optional>
Tooltip text shown while hovering the row.
</ParamField>

<ParamField path="SingleSelect" type="boolean" default="false">
Enables single-select picker semantics.
</ParamField>

<ParamField path="DefaultValue" type="any" optional>
Initial stored selection value.
</ParamField>

<ParamField path="InternalInfo.SingleSelect" type="boolean" optional>
Alias for `SingleSelect`.
</ParamField>

<ParamField path="InternalInfo.UniqueCommandId" type="string" optional>
Stable command ID. A random ID is generated when omitted.
</ParamField>

<ParamField path="InternalInfo.Bindable" type="boolean" default="false">
Adds a right-click menu for assigning or removing a keybind. The bound callback invokes the current selection callback path.
</ParamField>

<ParamField path="InternalInfo.StartupAvailable" type="boolean" default="false">
Adds a persisted startup flag to the context menu. The current selection implementation does not automatically execute the selection callback from that flag during initialization.
</ParamField>

<ParamField path="Aliases" type="string[]" optional>
Alternate Quick Commands names. `Info.Aliases` and `InternalInfo.Aliases` are also recognized.
</ParamField>

<ParamField path="Callback" type="function" optional>
Clicking the parent row calls the current selection callback. In Quick Commands, the selected value is passed first and any remaining arguments are forwarded afterward.
</ParamField>

## Quick Commands

A selection command can match an option by `Value` or display title. The matcher checks exact, prefix, and substring matches, trying longer multi-word prefixes before shorter ones.

```text
dest Nearest
dest Last Target
```

Arguments remaining after the matched option are forwarded to the selection callback:

```text
player Builderman
```

For a single-select selection, invoking the command with no arguments advances to the next option.

## Selection handle

```lua
local target = tab:AddSelection({
	Info = { Title = "Target" },
	SingleSelect = true,
	DefaultValue = "Nearest",
})

target:AddOption({ Info = { Title = "Nearest" }, Value = "Nearest" })
target:AddOption({ Info = { Title = "Self" }, Value = "Self" })

print(target:GetValue())
target:SetValue("Self")
target:UpdateSummary("Current target")
```

| Method | Behavior |
| :--- | :--- |
| `getValue()` / `GetValue()` | Returns the stored selection value. |
| `SetValue(value)` | Stores a value and updates the parent selected visual state. It does not click an option for you. |
| `UpdateSummary(text)` | Replaces the displayed summary with `<title> - <text>`. |
| `AddButton(config)` | Adds a child button. In single-select mode it behaves as an option and returns the option handle. Otherwise it returns the selection handle for chaining. |
| `AddOption(config)` | Adds a single-select-style child option and returns a small `{ UpdateSummary = ... }` option handle. |
| `AddTextBox(config)` | Adds a nested text input and returns the selection handle. |
| `AddSlider(config)` | Adds a nested slider and returns the selection handle. |
| `AddLabel(config)` | Adds a nested label and returns the selection handle. |

<Note>
For nested options, the library reads the option's `Value`, display title, callback, and an optional `InternalInfo.UniqueCommandId`. Other component flags are not propagated from the option config.
</Note>
